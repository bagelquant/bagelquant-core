# orthogonalize

```python
orthogonalize(source, *, factors, fit_intercept=False, name=None, metadata=None)
```

Remove the component of the first aligned panel explained by the remaining panels within each date cross-section.

## Parameters

**source** : Panel | Graph
: Input numeric `Panel` or single-output `Graph`.
**factors** : tuple[pl.DataFrame, ...]
: One or more factor `Panel` or single-output `Graph` inputs.
**fit_intercept** : bool, default `False`
: `fit_intercept` argument.
**name** : str | None, default `None`
: Optional graph-node name. A generated name is used when omitted.
**metadata** : Mapping[str, Any] | None, default `None`
: Optional metadata stored on the graph node.

## Returns

**Graph**
: Lazy single-output graph. Call `.compute()` to materialize a `Panel`.

## Examples

```python
orthogonalize(source, factors=(factors,))
```
