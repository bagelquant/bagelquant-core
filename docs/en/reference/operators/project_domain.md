# `project_domain`

Restrict an upstream value to an explicit membership Domain after computing its source universe.

## Contract

Registry: `bagelquant_core.operator.temporal.project_domain`. Version: `1`.

Peer inputs: 1 to 1 typed Nodes. Returns a deferred Node.

Execution: `lazy`; density: `sparse_ok`; traces: `parent_max`.

## Numerical signature

```python
project_domain(frame: 'pl.DataFrame', *, membership: 'pl.DataFrame') -> 'pl.DataFrame'
```

DataFrame arguments are Node dependencies in public calls. Scalar configuration is separate. Call `.compute()` to materialize.

## Executable example

```python
project_domain(source, membership=membership)
```
