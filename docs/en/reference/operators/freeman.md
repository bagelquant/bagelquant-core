# `freeman`

Apply the Freeman-Tukey square-root transform to stabilize count-data variance.

## Contract

Registry: `bagelquant_core.operator.variance_stabilization.freeman`. Version: `1`.

Peer inputs: 1 to 1 typed Nodes. Returns a deferred Node.

Execution: `lazy`; density: `sparse_ok`; traces: `passthrough`.

## Numerical signature

```python
freeman(frame: 'pl.DataFrame') -> 'pl.DataFrame'
```

DataFrame arguments are Node dependencies in public calls. Scalar configuration is separate. Call `.compute()` to materialize.

## Executable example

```python
freeman(source)
```

### source

| time | a | b | c |
|---|---:|---:|---:|
| 2024-01-02 | -2 | 0 | 1 |
| 2024-01-03 | -1 | 0.5 | 2 |

| time | a | b | c |
|---|---:|---:|---:|
| 2024-01-02 | missing | 1 | 2.41421 |
| 2024-01-03 | missing | 1.93185 | 3.14626 |
